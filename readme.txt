Floating WhatsApp chat button with customizable color, position, and pre-filled message.

== Description ==
Add a beautiful floating WhatsApp chat button to your WordPress site.

== Installation ==
1. Upload the folder to `/wp-content/plugins/`.
2. Activate the plugin.
3. Go to **WA Button** in the admin menu.
4. Enter your WhatsApp number and save.

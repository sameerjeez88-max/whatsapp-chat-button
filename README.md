# WhatsApp Chat Button

[![WordPress](https://img.shields.io/badge/WordPress-5.8%2B-blue)](https://wordpress.org)
[![PHP](https://img.shields.io/badge/PHP-7.4%2B-purple)](https://php.net)
[![License](https://img.shields.io/badge/License-GPLv2-green)](LICENSE)

A lightweight WordPress plugin that adds a floating WhatsApp chat button to your site.

## ✨ Features
- Floating WhatsApp button on frontend
- Custom phone number & pre-filled message
- Bottom-left or bottom-right positioning
- Custom color with auto-hover shade
- Enable/disable toggle
- Clean OOP code, translation-ready

## 📦 Installation
1. Download the ZIP
2. Upload to `wp-content/plugins/`
3. Activate in WordPress admin
4. Go to **WA Button** and enter your number

## 🛠️ Tech Stack
- PHP 7.4+
- WordPress Settings API
- Vanilla JS + CSS3
